ASidebar

Panel lateral / Navegación

La barra fija de la izquierda. Contiene el logo, perfil del cliente, menú de navegación y footer.

BTopbar

Barra superior / Header

Barra horizontal en la parte superior del contenido. Muestra el título de la sección y acciones principales.

CTab bar

Barra de pestañas / Tabs

Fila de pestañas que divide una sección en sub-vistas. Ej: Historias / Carruseles / Reels en Contenido.

DÁrea de contenido

Content area / Main panel

La zona principal donde vive el contenido de cada pantalla. Tiene scroll vertical independiente.

EPanel lateral derecho

Right panel / Side panel

Columna auxiliar a la derecha del contenido principal. Ej: Generando contenido, Cola de validación.

FFooter del sidebar

Client footer

Parte inferior fija del sidebar. Muestra el nombre del cliente, plan activo y acceso a configuración.

02 · Componentes del Sidebar

1 · Logo area
2 · Profile card
3 · Nav section label
4 · Nav item
5 · Nav item activo
6 · Client footer
1Logo area

Área del logo / Marca

Zona fija superior del sidebar con el logo y nombre de RIMA. Define la identidad visual del producto.

2Profile card

Tarjeta de perfil / Cliente activo

Muestra la foto y usuario de IG del cliente, con sus 3 métricas clave (seguidores, mensajes, ventas).

3Nav section label

Etiqueta de grupo / Título de sección

Texto pequeño en mayúsculas que agrupa ítems del menú. Ej: "COMENCEMOS" y "MI NEGOCIO".

4Nav item

Ítem de navegación / Enlace del menú

Cada fila clickeable del menú. Tiene un ícono de color, texto y opcionalmente un dot de estado.

5Nav item activo

Estado activo / Selected state

El ítem que está seleccionado actualmente. Se distingue por el fondo violeta y el borde de color.

6Client footer

Footer del cliente

Zona inferior del sidebar con nombre del cliente, plan, indicador de conexión y botón de configuración.

03 · Componentes de Contenido — Los bloques dentro de cada pantalla

Card / Tarjeta

Contenedor principal con fondo glass (semi-transparente). Todo el contenido vive dentro de cards.

Folder card

Card con encabezado coloreado que agrupa propuestas por temática. Tiene header + filas de items.

Row item / Fila

Fila individual dentro de una lista. Aparece en historial de entregas, cola de validación, etc.

06 · Vocabulario rápido — Términos que usaremos al hablar

Thumbnail

Imagen de vista previa de un Reel, Carrusel o Historia. La miniatura clickeable.

Carpeta

Agrupación de propuestas por temática dentro de Contenido. Ej: "Carpeta Ventas".

Propuesta

Una pieza de contenido generada por RIMA (un Reel, una secuencia de historias, etc.).

Copy

El texto/descripción que acompaña una publicación. Incluye caption y hashtags.

Referente

Una cuenta de IG o YouTube que modelamos. Aparece en Estudio de mercado.

Fuerza

Métrica RIMA: (Vistas+Comentarios)/Seguidores×100. Mide impacto real de un post.

Impacto

Métrica RIMA: Vistas / Vistas promedio del referente. Cuánto superó su propio promedio.

Cola de validación

Lista de piezas listas para enviar por Telegram al cliente para su aprobación.
